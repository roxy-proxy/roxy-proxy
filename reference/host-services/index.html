roxy

Host services

Everything a layer can do outside its own streams, each a capability granted in config (capabilities). A WASM layer calls them as the flow and endpoints imports named here; a service layer sends the matching messages on its stream (service layers), except endpoints.call, which a service does for itself. Both reach one host, so a call means the same and fails the same way for either kind. The caps on each (payload sizes, calls in flight, key length) are in fixed caps.

Endpoints (endpoints)

endpoints.call(name, head, body): roxy resolves the name to the configured URL, attaches the endpoint's headers (replacing any the layer set), applies the timeout, and enforces the address floor and deny lists. The layer cannot name a destination and never sees the credentials. Calls do not pass through the layer stack, so a monitor's own model call cannot recurse through it; the response goes back to the layer, not through the rules. Each call emits an endpoint_call flow event.

  • An exchange has at most 8 calls in flight. A further endpoints.call waits for one of them to be answered before it returns, and before roxy takes the call's body: a waiting call holds nothing.
  • The request body is buffered before the call (at most 16 MiB), and reading it counts against the timeout.
  • An unknown name, a denied address, a refused path, a timeout and a failure reach the layer as distinct error variants (destination-not-found, destination-denied, request-uri-invalid, timeout, internal), through the pending-response the call returns.

The endpoint's path setting:

pathtarget
fixed (default)the configured URL is the whole target; the request's path and query are ignored
prefixthe request's path, normalised (percent-encodings canonicalised, . segments removed), is appended under the configured path; its query follows the endpoint's own. A percent-encoded slash or backslash (%2F, %5C) is refused

A segment that starts with .., in any percent-encoded spelling and whatever follows the dots (..;x, which an origin that strips path parameters reads as ..), is refused in both modes: the call fails with request-uri-invalid, nothing is dialled, and the endpoint_call event records the refusal. Under prefix, text a layer reflects into the path can pick any route below the configured path, with roxy's credential attached.

State (state)

flow.state-get / flow.state-put: the state store the rules read as state["key"] and write with set_state. A key a layer writes is the key a rule reads, so a layer can leave a mark for a rule to deny on, and read what a rule left. Values are strings; a layer that wants state["k"] == "yes" to match writes yes. A state-put without a TTL gets the store's default (one hour). A miss returns none. A key over 1 KiB or a value over 64 KiB returns an error to the layer. A write when the store is full fails the exchange closed, as it does a rule's set_state; nothing is evicted. Only an enforce layer may write: a state-put from an observer fails the layer (layer_error, kind host) and the exchange goes on, like add-tag, since the store steers every flow's rules. The store survives a reload, under limits.max_state_entries.

Identity and config

flow.current(): the flow id, connection id, tags, and the principal as roxy established it (client IP, listener, TLS SNI). Key per-principal state on these, not on client-supplied session headers. flow.config() is the layer's config: value as a JSON document. A service gets both in its open message.

Record (record)

flow.record(kind, json) writes a layer_record event to the flow log with the flow id, layer name and timestamp. kind and every string value in the document pass through the secret redactor; a document that is not JSON fails the exchange. The call waits while the flow log is behind and is never dropped.

Metrics and log (metrics, log)

flow.metric-get(id, []) reads a metric for this flow's own key (the key fields evaluated on the request that left the addon stack); explicit key values are refused. A key with no entry reads none (a rule reads the same key as 0); an unknown id, or a key field the request does not have, fails the exchange. flow.log writes to roxy's operational log with the flow id and layer name.

Quarantine (quarantine)

flow.quarantine() puts the whole proxy into quarantine: the exchange it was called on is refused _quarantined (nothing of it is forwarded, whatever the layer answers), and so is every exchange after it, until an operator or the control plane lifts it. It is for what a layer is sure must stop the workload; one bad request is denied by answering it. Only an enforce layer may call it: from an observer it fails the layer (layer_error, kind host) and the exchange goes on, like add-tag. The quarantined flow event's cause is kind: layer with the layer's name and the flow. A config whose layers hold the capability needs roxy run --state-dir, as one with a quarantine rule does. A layer cannot terminate a client: it denies the exchange.
